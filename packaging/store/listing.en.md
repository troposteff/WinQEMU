## Product name

WinQEMU

## Description

Requires QEMU for Windows, installed separately and free: https://qemu.weilnetz.de/w64/ or the command "winget install SoftwareFreedomConservancy.QEMU". WinQEMU finds it by itself and guides you through installing it. WinQEMU is an independent, unofficial interface: it is neither affiliated with nor endorsed by the QEMU project. QEMU is a trademark of Fabrice Bellard.

WinQEMU is a Windows interface over QEMU, aiming at the comfort of VMware Workstation or Hyper-V. Create, run and manage virtual machines without typing a command line, with hardware acceleration through the Windows Hypervisor Platform.

At first start, WinQEMU checks that this PC is ready: QEMU found, hardware acceleration enabled, and what to do if not.

Virtual machines: a library in nested folders, a creation wizard, unattended installation of Windows 10/11 and Ubuntu, import from VMware, VirtualBox, Hyper-V and OVA, export to OVA, full and linked clones, templates, automatic start, machines left running in the background.

Console: integrated or full screen, the guest's resolution following the window, a shared clipboard, typing the clipboard into the guest, screen capture, files dropped onto the guest's desktop or copied back from it, sound with per-machine volume.

Snapshots: offline, live on the disks, or with memory under emulation; a snapshot tree; automatic snapshots.

Disks: create, grow, convert, compact, and encrypt (LUKS, AES-256), the password remembered in the Windows Credential Manager if you want.

Network: NAT with port forwarding, private, internal and external virtual networks, access from the local network in one click, shared folders, USB devices of this PC.

Command line: the winqemu command drives the running WinQEMU from any terminal.

In English and in French. Free software under the GNU GPL version 3: https://github.com/troposteff/WinQEMU

Optional: internal virtual networks use OpenVPN's TAP-Windows driver and external ones Npcap, both free and installed by you when you create such a network; WinQEMU shows where to get them.
